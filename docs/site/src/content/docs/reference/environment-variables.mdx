This page lists every `YAS_*` variable that yas reads, grouped by the subsystem that reads it. Set a variable in the environment of the process that reads it. Server settings go in the environment of `yas server` (or the service unit that starts it). Client settings go in the environment of the CLI command.

Unless a row says otherwise:

- The server samples a setting once at startup. Restart it to apply a change.
- A switch documented as "`0` disables" is on for any other value, including unset.
- A size or count that fails to parse falls back to the default.
- Sizes are bytes and durations are the unit in the name (`_MS` for milliseconds, `_SECS` for seconds).

## Client, target, and paths

| Variable              | Default                                            | Purpose                                                                                                                                                                                         |
| --------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `YAS_SOCK`            | automatic per-instance path                        | Unix socket (or Windows named pipe) of the local server. Overrides the packaged and automatic paths. See [Configuration files](/reference/configuration-files#sockets-and-runtime-directories). |
| `YAS_TARGET`          | unset                                              | Default target for CLI commands. `--on` overrides it; it overrides `yas.target` in `yas.conf`.                                                                                                  |
| `YAS_SERVER_NAME`     | `default`                                          | Instance name for `yas server --name` and for extensions that derive per-instance paths.                                                                                                        |
| `YAS_HUB`             | `yas.run`                                          | Signaling hub URL for `share:` targets and `yas share` (same as `--hub`).                                                                                                                       |
| `YAS_CONFIG`          | `<config dir>/yas.conf`                            | Path of `yas.conf`.                                                                                                                                                                             |
| `YAS_REMOTES`         | `<config dir>/yas.remotes`                         | Path of `yas.remotes`, which a server imports once when it has no `remotes` key.                                                                                                                |
| `YAS_FORWARDS`        | `<config dir>/yas.forwards`                        | Path of `yas.forwards`.                                                                                                                                                                         |
| `YAS_KV_PATH`         | `<state dir>/yas/instances/<name>/kv.redb`         | Path of the KV database.                                                                                                                                                                        |
| `YAS_EXTENSION_PATH`  | `<state dir>/yas/instances/<name>/extensions.redb` | Path of the extension catalogue database.                                                                                                                                                       |
| `YAS_EXT_DB`          | unset                                              | Alternate name for `YAS_EXTENSION_PATH`, read when that is unset.                                                                                                                               |
| `YAS_WASM_CACHE`      | `<cache dir>/yas/instances/<name>/wasm`            | Directory of the extension object cache.                                                                                                                                                        |
| `YAS_PROXY`           | enabled                                            | `0` makes the CLI connect to `ssh:` targets in-process instead of through the per-user proxy.                                                                                                   |
| `YAS_PROXY_SOCK`      | per-user automatic path                            | Socket of the per-user connection proxy.                                                                                                                                                        |
| `YAS_PROXY_UID`       | unset                                              | Numeric UID the proxy socket must belong to. Requires an explicit `YAS_PROXY_SOCK`.                                                                                                             |
| `YAS_PROXY_IDLE`      | `300` when yas spawns the proxy                    | Seconds the proxy stays up with no clients.                                                                                                                                                     |
| `YAS_SSH_KNOWN_HOSTS` | `~/.ssh/known_hosts`                               | Known-hosts file for `ssh:` targets.                                                                                                                                                            |
| `YAS_VERBOSE`         | unset                                              | `1` turns on verbose server logging, as `--verbose` does.                                                                                                                                       |

## Install and update

| Variable          | Default                             | Purpose                                                                                                                                                                        |
| ----------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `YAS_PREFIX`      | chosen by `install.sh`              | Install prefix. SSH auto-install sets `$HOME/.local`.                                                                                                                          |
| `YAS_INSTALL_DIR` | `%LOCALAPPDATA%\yas\bin` on Windows | Install directory for `install.ps1`. `install.sh` treats it as a legacy bin directory: it strips a trailing `/bin` and uses the rest as the prefix when `YAS_PREFIX` is unset. |
| `YAS_GPL`         | unset                               | `1` installs the GPL build with x264. `yas update` passes it through.                                                                                                          |
