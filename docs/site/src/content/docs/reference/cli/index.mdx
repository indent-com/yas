## Global options

These options apply to every subcommand.

- `--on <ON>`

  Remote to connect to: a URI (ssh:host, tcp:h:p, socket:/p, share:pass, local[:name]) or the name of a remote on the home server (see `yas remote`). Overrides `YAS_TARGET` and yas.conf `yas.target`

- `--hub <HUB>`

  Signaling hub URL

  Default: `yas.run`. Environment: `YAS_HUB`.

- `--json`

  Emit NDJSON for an extension-provided `@name` command

  This root option must precede `@name`. A `--json` after the namespace is passed verbatim to the extension command.
