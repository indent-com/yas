Share via WebRTC

Set `YAS_PASSPHRASE` to use a deterministic passphrase (default: random).

```text
Usage: yas share [OPTIONS]
```

Options:

- `--quiet`

  Don't print the sharing URL

- `--verbose`

  Print detailed connection diagnostics to stderr
