Hash a yas edge passphrase for `YAS_PASSPHRASE`

Prints an argon2id PHC string suitable for `YAS_PASSPHRASE`. If VALUE is omitted or "-", reads from stdin. The stored hash is salted; browser clients still enter the original plaintext passphrase.

```text
Usage: yas hash-passphrase [OPTIONS] [VALUE]
```

Arguments:

- `[VALUE]`

  Plaintext passphrase to hash (or -/omitted to read from stdin)
