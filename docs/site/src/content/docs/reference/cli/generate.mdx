Generate man pages and shell completions

Writes man pages for all yas binaries and shell completions (fish, bash, zsh) for the yas CLI into the given directory.

```text
Usage: yas generate [OPTIONS] <OUTPUT>
```

Arguments:

- `<OUTPUT>`

  Output directory (e.g. /usr/share)

Options:

- `--markdown`

  Write the docs site's MDX CLI reference into the directory instead
