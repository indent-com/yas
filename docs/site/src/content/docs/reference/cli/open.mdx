Open the terminal UI in the browser

Opens the browser with the local yas server and every named remote it publishes. Manage remotes with `yas remote add/remove` or through the Remotes dialog in the browser. `--on` and `--hub` are refused: the UI always starts from the local server.

Examples:

```text
yas open                        # local + all configured remotes
yas remote add rabbit ssh:rabbit
yas open                        # now includes rabbit
```

```text
Usage: yas open [OPTIONS]
```

Options:

- `--port <PORT>`

  Bind browser UI to a specific port (default: random)
