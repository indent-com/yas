---
title: "yas"
description:
  "yas is a terminal multiplexer and experimental Wayland compositor that streams terminals and
  graphical apps to browsers and lets scripts and AI agents drive them from the command line."
tableOfContents: false
---

yas runs terminals on a server and keeps them running while you come and go. Open them from a
browser on any device, reattach after a laptop sleeps or a network changes, and share a live
session with a link. Every action in the browser is also a CLI subcommand, so a script or an AI
agent can start a terminal, type into it, wait for a command to finish, and read the output. On
Linux, the same server runs a headless Wayland compositor and streams graphical apps as video.

yas is one binary with no required dependencies. It runs on Linux, macOS, and Windows; the
compositor is Linux only.

<Steps titleSize="h3">
  <Step title="Install yas">

    ```bash
    curl -sf https://yas.run | sh
    ```

    On Windows, run `irm https://yas.run/install.ps1 | iex` in PowerShell. See
    [Installing yas](/getting-started/installing).

  </Step>
  <Step title="Open it in a browser">

    ```bash
    yas open
    ```

    The server starts on first use, and the browser opens the workspace. See
    [Workspaces and layout](/browser/workspaces).

  </Step>
  <Step title="Drive a terminal from the command line">

    ```bash
    yas terminal start htop   # prints the new terminal's ID
    yas terminal show 1       # prints its visible text
    ```

    See [Controlling terminals](/terminals/controlling-terminals).

  </Step>
  <Step title="Reach another machine">

    Save an SSH host with `yas remote add box ssh:box`, then `yas open` shows it next to your local
    server. yas installs itself on the remote the first time. To give someone else a link, run
    `yas share`. See [Remotes](/remote/remotes) and [Sharing over WebRTC](/remote/sharing).

  </Step>
</Steps>
