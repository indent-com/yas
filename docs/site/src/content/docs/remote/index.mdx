Use an SSH remote when you can reach the machine over SSH, a share for a link anyone with the passphrase can open, and an uplink when the only path is a relay you do not trust.

<CardGrid>
  <Card title="Remotes" href="/remote/remotes">

    which servers the browser shows next to your own.
  </Card>
  <Card title="Sharing over WebRTC" href="/remote/sharing">
    Publish a server through the yas.run hub so anyone with the passphrase can
    open it in a browser or reach it from the CLI.
  </Card>
  <Card title="Uplink" href="/remote/uplink">
    Expose a server through a relay you do not trust, with end-to-end encryption
    between X25519 keys that each side pins.
  </Card>
  <Card title="Port forwarding and SOCKS" href="/remote/port-forwarding">

    TLS, or through a local SOCKS5 proxy.
