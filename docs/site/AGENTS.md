# yas docs site

Public documentation at docs.yas.run. One `.mdx` file per page under `src/content/docs/`.

This project has its own lockfile outside the `js/` pnpm workspace. Target its directory explicitly
(`pnpm --dir docs/site ...`) rather than using a workspace filter.

When changing layouts or routes, preserve the per-page Markdown alternatives (`/page/index.md`),
`llms.txt`, `llms-full.txt`, and the agent directive, not only the rendered HTML.

## Structure

- Each top-level directory is a sidebar group. Its `index.mdx` sets `sidebar.order`,
  `sidebar.group.label`, and `sidebar.group.icon`, then gives one sentence and a `CardGrid` with one
  `Card` per page.
- Leaf pages set `sidebar.order` to the group's order times ten plus the page position (group 3,
  second page: `32`).
- `reference/cli/` is generated by `bin/generate-cli-docs` from the clap definitions in
  `crates/cli/src/cli.rs`. Do not edit it by hand; CI fails when it is stale.
- `reference/environment-variables.mdx` must list every `YAS_*` variable the code reads.
  `bin/check-env-docs` enforces it in CI.
- `changelog.mdx` has one `##` section per release, newest first. Write the section by hand in the
  release pull request.

## Writing rules

- Every page documents the current release. Describe what yas does now; never describe how it used
  to behave.
- One capability per page. The first paragraph says what the capability is and where it applies.
  Then give imperative steps, then options as bullets. Put limits, error cases, and platform caveats
  last, in an `Aside` when they are short.
- `description` in frontmatter is one sentence. It appears on cards, in `llms.txt`, and in social
  images.
- Second person, present tense, active voice, sentence-case headings.
- One fact per sentence and one idea per paragraph. Delete a sentence that only announces what
  follows, and delete a heading that only restates the next line.
- Say what a command prints, field by field, when a reader has to parse it.
- Use the verb that literally describes the action. No metaphor where a literal description fits.
- No em dashes. Recast the sentence. A semicolon usually marks a sentence that should be two.
- No "not X, but Y" constructions, rhetorical questions, benefit tails, or self-appraisal ("worth
  noting", "importantly").
- No empty quality words: robust, seamless, powerful, blazing, first-class, simply, just, easy.
- No e.g. or i.e.
- Code blocks show commands a reader runs and output they see. Every example must have been run
  against the current release. Use `bash` for commands and `text` for output.
- Mark experimental features with `<Aside type="caution" title="Experimental">` near the top of the
  page, saying what is experimental and which platforms it runs on.

## Terminology

- **yas**, lowercase, for the program, the project, and the protocol ("the yas protocol"). Code
  identifiers keep their spelling (`YAS_SOCK`, `yas.v1`, `yas.relay`).
- **server**: the `yas server` process. **instance**: a named server (`--name`, `local:NAME`).
  **home server**: the server a browser or CLI connects to first.
- **terminal** on user pages. Use **PTY** only on reference and internals pages.
- **surface**: a graphical window from the compositor.
- **client**: anything connected to a server: a browser tab, a CLI command, an embedded component.
- **remote**: a saved target added with `yas remote add`. **route**: a remote as the home server
  publishes it to clients. Reserve **relay** for the untrusted server an uplink passes through.
- **edge** (`yas edge`), **share** (`yas share`), **uplink** (`yas uplink`), **hub** (the WebRTC
  signaling service, `yas.run` by default).
- **family**: a protocol feature namespace (`yas.terminal`, `yas.fs`). Use only on internals and
  reference pages.

## Verification

- Check every behavioral claim against the code. Older Markdown in the repository has drifted.
- Run commands against a private server, never one your shell may already point at:

  ```bash
  D=$(mktemp -d); yas server --socket "$D/yas.sock" --name docs &
  export YAS_SOCK="$D/yas.sock"
  yas terminal list
  yas quit
  ```
